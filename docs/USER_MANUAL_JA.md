## 1. はじめに — 画面の構成

アプリを起動すると、メイン画面が表示されます。

![メイン画面](images/01-main-window.png)
*図 1: メイン画面*

画面上部のバーには、次のボタンがあります。

| ボタン | 説明 |
|---|---|
| **● Active** | 現在の稼働状態を示します。 |
| **📋 History** | 変更履歴・バックアップ履歴を表示します。 |
| **📈 Dashboard** | すべてのウォッチの状態を 1 画面で表示します。 |
| **📜 Logs** | アプリのログを表示します。 |
| **🔧 Admin** | 管理者設定を開きます（`Ctrl` + `,`）。 |
| **❌ Quit** | アプリを終了します。 |

画面中央には、登録した **ウォッチ**（監視フォルダ）がカード形式で 1 つずつ表示されます。各カードには **Backup Now**（今すぐバックアップ）ボタンと **More ▾**（その他の操作）ボタンがあります。

## 2. 初期設定

### 2-1. 管理者パスワードを設定する

初回起動時に、管理者パスワードの設定画面が表示されます。このパスワードは設定画面を保護し、一般ユーザーがバックアップを勝手に変更・停止できないようにするためのものです。

![管理者パスワードの設定](images/02-set-admin-password.png)
*図 2: 管理者パスワードの設定*

1. パスワードを入力します。
2. 確認のため、もう一度同じパスワードを入力します。
3. **OK** をクリックします。

> **注意:** このパスワードは設定画面を開くたびに必要になります。忘れないように保管してください。

### 2-2. 表示言語を確認する

本アプリは既定で日本語表示です。英語に切り替える場合は、**🔧 Admin → 全般 → 言語** から選択します。

> **重要:** 言語の変更はアプリの再起動後に反映されます。

![言語の設定](images/03-language-setting.png)
*図 3: 言語の設定（🔧 Admin → 全般）*

## 3. ウォッチ（監視フォルダ）を追加する

「ウォッチ」とは、監視してバックアップする対象のフォルダのことです。フォルダは何個でも登録でき、それぞれ独立した設定を持ちます。

### 手順

**① 管理者設定を開く**

メイン画面の **🔧 Admin** をクリックし、管理者パスワードを入力します。

**② ウォッチタブを開く**

**ウォッチ** タブを選択し、**➕ ウォッチを追加** をクリックします。

![ウォッチタブ](images/04-admin-watches-tab.png)
*図 4: 管理者設定 → ウォッチタブ*

**③ 監視元フォルダと保存先を指定する**

「ウォッチを追加」画面が表示されます。

![ウォッチの追加](images/05-add-watch-dialog.png)
*図 5: ウォッチの追加画面*

| 項目 | 入力内容 |
|---|---|
| **名前** | このウォッチの名前（例: 「営業部 共有フォルダ」）。一覧や履歴に表示されます。 |
| **監視するフォルダ** | バックアップしたいフォルダ。**Browse**（参照）から選択します。 |
| **バックアップの保存先** | バックアップの保存場所。ローカルフォルダのほか、SFTP・SMB・Google Drive などのリモート保存先も指定できます。 |

> **リモート保存先を指定した場合:** 必ず **接続テスト** ボタンを押し、認証情報が正しいことを確認してください。

**④ スケジュールとオプションを設定する（任意）**

**▶ スケジュールとオプション** をクリックすると、詳細設定が展開されます。ここで実行間隔・暗号化・圧縮などを設定できます。後から変更することもできます。

![スケジュールとオプション](images/06-add-watch-options.png)
*図 6: スケジュールとオプション（展開後）*

**⑤ 追加を確定する**

**ウォッチを追加** ボタンをクリックします。メイン画面に新しいカードが表示されます。

## 4. ウォッチを編集する

登録済みのウォッチの設定は、いつでも変更できます。方法は 2 通りあります。

- **方法 A:** メイン画面のカードで **More ▾ → ⚙ ウォッチ設定…** をクリックします。
- **方法 B:** **🔧 Admin → ウォッチ** タブで、対象の行の **✏ Edit** をクリックします。

![ウォッチの編集](images/07-edit-watch-dialog.png)
*図 7: ウォッチの編集画面*

この画面では、次の項目を設定できます。すべてを設定する必要はありません。必要なものだけ変更してください。

| 項目 | 説明 |
|---|---|
| **監視するフォルダ / 保存先** | フォルダや保存先を変更します。 |
| **追加の保存先** | 2 か所以上へ同時にバックアップしたい場合に追加します（例: ローカルと Google Drive の両方）。 |
| **暗号化** | バックアップの中身を保護します。バックアップ用のドライブを紛失しても、中のファイルは第三者には読めません。 |
| **除外設定** | バックアップしたくないファイル・フォルダを指定します。 |
| **PC の認証情報** | 共有フォルダで「誰が変更したか」を記録するために必要です。 |
| **速度の制限** | このフォルダのバックアップが回線を占有しないように、転送速度の上限を設定します。 |

設定後、**変更を保存** をクリックします。

## 5. ウォッチを削除する

**① 🔧 Admin → ウォッチ** タブを開きます。

**②** 削除したいウォッチの行にある **🗑 Remove** をクリックします。

![ウォッチの削除](images/08-remove-watch-button.png)
*図 8: ウォッチの削除（🗑 Remove）*

**③** 確認画面が表示されます。**Yes** をクリックすると削除されます。

![削除の確認](images/09-delete-watch-confirm.png)
*図 9: 削除の確認画面*

> **重要:** ウォッチを削除しても、**すでに作成済みのバックアップファイルは削除されません**。監視の対象から外れるだけです。バックアップファイルが不要な場合は、保存先のフォルダから手動で削除してください。

## 6. バックアップを実行する

### 6-1. 今すぐバックアップする

メイン画面で、対象のウォッチのカードにある **Backup Now** をクリックします。

![バックアップの実行](images/10-backup-now-progress.png)
*図 10: バックアップの実行中（進捗表示）*

実行中は進捗バーが表示され、進捗率・残り容量・残りファイル数・転送速度が確認できます。完了するとボタンは **Backup Now** の表示に戻ります。

> 初回はすべてのファイルをコピーするため時間がかかります。2 回目以降は変更されたファイルだけをコピーするため、はるかに短時間で完了します。

### 6-2. その他のバックアップ操作（More ▾）

カードの **More ▾** をクリックすると、次の操作を選べます。

![More メニュー](images/11-more-menu.png)
*図 11: More ▾ メニュー*

| メニュー | 説明 |
|---|---|
| **⏸ Pause / ▶ Resume** | このフォルダの監視と自動バックアップを一時停止 / 再開します。 |
| **⟳ フル強制バックアップ** | 変更分だけでなく、すべてのファイルを改めてバックアップします。 |
| **🔍 ドライラン** | 実際にはコピーせず、どのファイルがバックアップされるかだけを確認します。 |
| **▶ 検証** | バックアップしたファイルが壊れずに読み取れる状態かを確認します。 |
| **↩ 復元** | バックアップから、指定したフォルダへファイルを戻します。 |
| **🏠 元の場所に復元** | 元のフォルダへ、そのまま戻します。 |
| **📂 フォルダを開く** | バックアップの保存先をエクスプローラーで開きます。 |
| **⚙ ウォッチ設定…** | このフォルダの編集画面を開きます。 |
| **🛟 診断情報のエクスポート…** | 設定・履歴・ログを 1 つのファイルにまとめます。問題が起きたときに、サポートへ送付するために使います。パスワードは自動的に取り除かれます。 |

### 6-3. すべてのウォッチを一括バックアップする

タスクトレイのアイコンを右クリックし、**⬆ Backup All Now** を選択します。

## 7. 自動バックアップを設定する

**🔧 Admin → 全般 → スケジュールと制限** で設定します。

![スケジュールの設定](images/12-admin-schedule.png)
*図 12: スケジュールと制限*

| 設定 | 説明 |
|---|---|
| **自動バックアップ** | 有効にすると、指定した間隔で自動的にバックアップします。 |
| **実行間隔（分）** | 何分ごとにバックアップするか。 |
| **実行時刻** | 特定の時刻（例: 02:00）に実行します。曜日ごとの指定も可能です。 |
| **バックアップ実行時間帯** | 自動バックアップを許可する時間帯（例: 22:00〜06:00）。業務時間中の実行を避けられます。 |
| **保持期間** | 指定日数より古いバックアップを自動的に削除します。 |

### 自動シャットダウン

**🔧 Admin → 全般 → 自動シャットダウン** で、**すべてのバックアップ完了時に PC を自動的にシャットダウン** を有効にできます。

![自動シャットダウン](images/13-auto-shutdown.png)
*図 13: 自動シャットダウンの設定*

> シャットダウンの前に 60 秒のカウントダウン画面が表示されます。PC を使い続ける場合は、この画面でキャンセルできます。

## 8. 履歴を確認する

メイン画面の **📋 History** をクリックします。履歴画面には複数のタブがあります。

### 8-1. 変更履歴 — 「誰が変更したか」

監視フォルダ内で **追加・変更・削除・名前変更** されたファイルが一覧表示されます。共有フォルダの場合、**その変更を行ったユーザー / PC** も表示されます。

![変更履歴](images/14-change-history.png)
*図 14: 変更履歴タブ*

> **「Unknown」と表示される場合:** 変更者を確実に特定できなかったことを意味します。本アプリは推測を行わず、確定できない場合は正直に「Unknown」と表示します。継続して Unknown になる場合は、**ウォッチの編集 → PC の認証情報** の設定を確認してください。

### 8-2. バックアップ履歴

過去のバックアップの実行結果（成功 / 失敗）、日時、ファイル数、容量が確認できます。

![バックアップ履歴](images/15-backup-history.png)
*図 15: バックアップ履歴タブ*

### 8-3. ファイル検索

すべてのウォッチのバックアップを横断して、ファイル名で検索できます。「あのファイルはどのバックアップに入っているか」を調べるときに使用します。

![ファイル検索](images/16-file-search.png)
*図 16: 🔍 ファイル検索タブ*

1. ファイル名の一部を入力します。
2. 必要に応じて、対象のウォッチを絞り込みます。
3. **検索** をクリックします。
4. 該当するウォッチ名・バックアップ日時・ファイルパス・サイズが表示されます。

## 9. ログを確認する

### 9-1. ログ画面を開く

メイン画面の **📜 Logs** をクリックします。アプリの動作ログが表示されます。エラーの原因を調べるときに使用します。

![ログ画面](images/17-logs-window.png)
*図 17: ログ画面*

### 9-2. 管理者設定のログタブ

**🔧 Admin → ログ** タブでは、次の操作ができます。

![ログタブ](images/18-admin-logs-tab.png)
*図 18: 管理者設定 → ログタブ*

| ボタン | 説明 |
|---|---|
| **🔄 更新** | 最新のログを再読み込みします。 |
| **🗑 ログをクリア** | ログを消去します。 |
| **💾 ログをエクスポート** | ログをファイルに保存します。 |

### 9-3. ログファイルの保存場所

ログはアプリのフォルダ内の `logs/backupsys.log` に保存されます（2 MB × 5 ファイルで自動ローテーション）。

> **サポートに問い合わせる場合:** メイン画面のカードで **More ▾ → 🛟 診断情報のエクスポート…** を使用すると、設定・履歴・ログが 1 つの ZIP にまとまります。パスワードは自動的に伏字処理されるため、そのまま送付できます。

## 10. ファイルを復元する

**①** メイン画面で、対象のウォッチのカードにある **More ▾ → ↩ 復元** をクリックします。

**②** 復元したいバックアップ（日時）を選択します。

![復元](images/19-restore-dialog.png)
*図 19: 復元画面*

**③** 復元先のフォルダを指定します。元の場所に戻す場合は **🏠 元の場所に復元** を使用します。

**④** 増分バックアップの場合、**チェーン全体を復元** を選ぶと、指定した日時までのすべての変更が順に適用され、その時点のフォルダ状態が正確に再現されます。

**⑤** 復元先に同名のファイルが既に存在する場合は、上書きするかどうかの確認画面が表示されます。

## 11. タスクトレイから操作する

本アプリはバックグラウンドで常駐します。画面右下（時計の近く）のタスクトレイアイコンを右クリックすると、次の操作ができます。

![トレイメニュー](images/20-tray-menu.png)
*図 20: タスクトレイのメニュー*

| メニュー | 説明 |
|---|---|
| **Open Dashboard** | メイン画面を開きます。 |
| **⬆ Backup All Now** | すべてのウォッチを一括でバックアップします。 |
| **🔍 Run Integrity Check Now** | バックアップの整合性チェックを今すぐ実行します。 |
| **🔧 Admin Settings** | 管理者設定を開きます。 |
| **📋 Change History** | 変更履歴を開きます。 |
| **Quit** | アプリを終了します。 |

> **注意:** メイン画面の **❌ Quit** またはトレイの **Quit** を実行するとアプリが終了し、自動バックアップと監視も停止します。ウィンドウを閉じるだけであれば、アプリはトレイで動作を続けます。

## 12. 困ったときは

| 症状 | 対処 |
|---|---|
| トレイにアイコンが見つからない | タスクバーの隠れているアイコン（`^` マーク）を確認してください。 |
| 変更履歴が「Unknown」になる | **ウォッチの編集 → PC の認証情報** を設定してください。設定には管理者権限が必要です。 |
| 開いたままのファイルがバックアップされない | 使用中のファイルをコピーするには管理者権限が必要です。`BackupSystem.exe` を右クリックし、「管理者として実行」を選んでください。 |
| リモート保存先へ保存できない | **ウォッチの編集** から **接続テスト** を実行し、認証情報を確認してください。 |
| バックアップが自動実行されない | ウォッチが **⏸ 一時停止** になっていないか、**バックアップ実行時間帯** の範囲外でないかを確認してください。 |
| 言語を変更したのに反映されない | 言語の変更はアプリの再起動後に反映されます。 |

問題が解決しない場合は、**More ▾ → 🛟 診断情報のエクスポート…** で ZIP を作成し、サポートへ送付してください。
