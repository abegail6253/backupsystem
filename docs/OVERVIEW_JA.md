# バックアップシステム — できること

**バージョン:** 1.1.10 · Windows デスクトップアプリケーション

大切なフォルダを見守り、自動的に安全な場所へコピーします。共有フォルダの場合は、**誰が** ファイルを追加・変更・削除したかも記録します。

タスクトレイに常駐して静かに動作します。一度設定すれば、あとは誰も操作を覚えておく必要はありません。

---

## 1. バックアップ

| 機能 | どう役立つか |
|---|---|
| **フォルダを何個でも登録できる** | 保護する対象のフォルダを「ウォッチ」と呼びます。いくつでも追加でき、それぞれに別の保存先と別のスケジュールを設定できます。 |
| **変更をすぐに検知する** | ファイルが変更された瞬間に検知します。決まった時刻のスキャンを待つ必要はありません。 |
| **変更された分だけコピーする** | 初回はすべてをコピーしますが、2 回目以降は実際に変更されたファイルだけをコピーします。そのため速く、保存容量も大幅に節約できます。 |
| **事前に確認できる** | 実際にコピーする前に、どのファイルがバックアップされるかだけを確認できます。 |
| **使用中のファイルもバックアップできる** | 現在開かれているファイル（Outlook のメールデータ、データベース、誰かが開いたままのファイルなど）は通常コピーできませんが、本アプリはそれらもバックアップできます。 |
| **バックアップを保護する（暗号化）** | バックアップの中身を読み取れないように保護できます。バックアップ用のドライブを紛失・盗難された場合でも、中のファイルは第三者には使えません。 |
| **容量を小さくする（圧縮）** | バックアップの容量を削減できます。そのぶん実行時間は少し長くなります。 |

## 2. 自動実行

| 機能 | どう役立つか |
|---|---|
| **一定間隔で実行** | 指定した分ごとに自動でバックアップします。 |
| **決まった時刻に実行** | 例えば「平日の午前 2 時」など。曜日も指定できます。 |
| **業務時間外だけ実行** | 自動バックアップを実行する時間帯（例: 22:00〜06:00）を限定でき、業務中に動作して作業の妨げになることを防げます。 |
| **終わったら PC を自動で電源オフ** | **すべての** バックアップが完了すると、PC を自動的にシャットダウンします。夜間の実行に最適です。実行前に 60 秒のカウントダウンが表示されるため、まだ作業中の場合は中止できます。 |
| **USB ドライブを挿すだけで実行** | バックアップ用のドライブを接続すると、自動的にバックアップが始まります。操作も、どのドライブだったか覚えておく必要もありません。 |
| **作業の邪魔をしない** | PC が忙しいときは実行を見送るため、作業が遅く感じることはありません。モバイル回線（従量制課金接続）の使用中は一時停止し、データ通信量の浪費も防ぎます。 |
| **Windows と一緒に起動** | PC の電源を入れると自動的に起動するため、うっかり止めたままになることがありません。 |

## 3. バックアップの保存先

1 つのフォルダを **複数の場所へ同時に** バックアップできます。例えばローカルのドライブと Google Drive の両方に保存しておけば、万一オフィスが被災しても安心です。

| 保存先 | 備考 |
|---|---|
| **この PC 内のフォルダ、USB / 外付けドライブ** | 最も簡単な方法です。 |
| **共有フォルダ・NAS** | オフィスで一般的な方法です。 |
| **Google Drive** | ブラウザから通常どおりサインインします。 |
| **社内のファイルサーバー（SFTP / FTP）** | 情報システム部門がサーバーを用意している場合に使用します。 |

リモートの保存先には **接続テスト** ボタンがあり、大切なファイルを預ける前に、実際に接続できるかを確認できます。

## 4. 「誰が変更したか」がわかる

本アプリの最大の特長で、共有フォルダで特に役立ちます。

| 機能 | どう役立つか |
|---|---|
| **すべての変更を記録** | 監視フォルダ内で **追加・変更・削除・名前変更** されたファイルを、発生と同時に記録します。 |
| **実行した人がわかる** | 共有フォルダの場合、どの担当者・どの PC が変更したかを特定します。ファイルが消えた・上書きされたときに、誰がいつ行ったのかを確認できます。 |
| **同僚の PC の共有フォルダにも対応** | 他の人の PC 上にある共有フォルダでも動作します。 |
| **推測せず「Unknown」と表示** | 変更者を確実に特定できない場合は、誤った人の名前を出さずに正直に「Unknown」と表示します。記録された内容は信頼できます。 |

## 5. ファイルを元に戻す

| 機能 | どう役立つか |
|---|---|
| **過去のバックアップから復元** | 日時を選び、戻す場所を指定すれば、ファイルが復元されます。 |
| **元の場所に戻す** | 元のフォルダへ、そのまま復元できます。 |
| **特定の日の状態に巻き戻す** | 指定した時点のフォルダの状態を、そのとおりに再現します。 |
| **すべてのバックアップから探す** | ファイル名で、すべてのフォルダのバックアップを横断して検索できます。「名前はわかるが、どこ・いつのバックアップかわからない」ときに便利です。 |

## 6. 状態を確認する

| 機能 | どう役立つか |
|---|---|
| **バックアップ履歴** | 各バックアップが成功したか失敗したか、いつ実行し、どれだけコピーしたかがわかります。 |
| **すべてを 1 画面で確認** | 保護しているすべてのフォルダの状態を、1 つの画面でまとめて確認できます。 |
| **定期的な健全性チェック** | バックアップしたファイルが破損せずに読み取れる状態かを、定期的に自動で検証します。いざ必要になった日に「壊れていた」と気づく事態を防げます。 |
| **ログ** | 動作の詳細な記録です。問題を調べるときに使用します。 |
| **サポート用ファイルをワンクリックで作成** | 設定・履歴・ログを 1 つのファイルにまとめて送付できます。パスワードは自動的に取り除かれます。 |
| **ディスクを使い切らない** | 古いバックアップを自動的に削除したり、最新の数世代だけを残したり、容量の上限を設定できます。 |
| **回線を占有しない** | バックアップが使う通信速度を制限できます。例えば日中は低速に、夜間は全速力に設定できます。 |

## 7. 通知

バックアップが失敗したときに知らせます。問題が何週間も見過ごされることを防げます。通知方法は次のとおりです。

- **メール**
- **スマートフォンへの通知**
- **Telegram**
- **Slack や Discord などのチャットアプリ**

既定では **失敗したときだけ** 通知します。成功時にも通知するよう設定できます。

## 8. 日常の使い方と安全性

| 機能 | どう役立つか |
|---|---|
| **バックグラウンドで動作** | 時計の横のタスクトレイに常駐します。右クリックで開きます。 |
| **管理者パスワード** | 設定を保護し、担当者が誤ってバックアップを変更・停止することを防ぎます。 |
| **パスワードを安全に保管** | 入力したパスワードは Windows のパスワード保管庫に保存され、誰でも読めるファイルには残りません。 |
| **日本語と英語** | 設定画面で切り替えられます。 |
| **ライト / ダークの表示** | 見やすい方を選べます。 |
| **設定を別の PC へコピー** | 設定を書き出して別の PC に読み込めます。すべて入力し直す必要はありません。 |
| **USB メモリから実行** | 設定を含むアプリ全体を USB ドライブに入れて持ち運べます。 |
